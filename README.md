# Tic Tac Toe

A simple command-line Tic Tac Toe game made in Python where the player competes against a computer opponent.

## Features

* Player vs. computer
* Interactive command-line board
* Player uses `X`
* Computer uses `O`
* Random computer moves
* Prevents occupied spaces from being selected
* Handles invalid input
* Detects wins and draws

## Technologies Used

* Python
* `random`

## How to Play

Run the Python program and choose a space from `1-9` when prompted.

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

The player is `X` and the computer is `O`.

Get three of your symbols in a row to win.
